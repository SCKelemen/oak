# Note: the OS pilot's consolidated requests — assessment and dispositions

**Status: rounds one and two landed, 2026-09-13.** Source: the OS (hypervisor) pilot's
consolidated list, synthesized from its `OAK-NEEDS.md` and its design logs
0102–0105, grouped by leverage. The pilot's numbering is kept.

| # | Request | Determination | Disposition |
| --- | --- | --- | --- |
| R1 | Multiple live instances of a stateful module, mutated in place, without by-value copies of large state (three stage2 regimes at once; a ~400 KiB pool) | **A port rewrite with existing features, plus one backend fix.** N instances are an owned array of the record and one span over it; a store through an element (`s[dom].pool[k] = v`) and a field write (`s[dom].count = ...`) are in place. The one copy the backend did make — a field **read** through a span element returned the whole record by value from the checked helper — is removed: `s[dom].count` now selects the element in place. | **Landed** (`50-borrowing.md` §8e, `90-backend.md` §8; `compiler/e2e_os_round1_test.go`). Bind the span in a block; read the owner after it. Whole-element binding `st: Stage2 = s[dom]` remains the explicit copy. |
| R2 | Module-level constants as C constants, not mutable statics (`static u64 page_size = 16384;` makes `/ page_size` a hardware division) | **A codegen gap, confirmed from the generated C.** | **Landed** (`90-backend.md` §8a): a scalar global with a constant initializer that no statement assigns, index-assigns, borrows, or addresses is `static const`; the C compiler folds it. A written global stays `static`. |
| R3 | Bounds-check elision for owned fixed arrays (`state: [4]u8` under `i < len(state)`) | **Half confirmed.** A local owned array and a record's array field already elide under the canonical loop; a **top-level** table did not, because extent facts admitted only local containers. | **Landed**: a top-level owned array is admitted in a fact's container position (its static extent is a fact of the program; the index stays local). `TABLE[i]` under `i < len(TABLE)` is direct. If a pinned port still shows checks, its loop is outside the canonical shape (the index must change only as the body's last statement) — send the loop. |
| R4 | `o + 3 < len(b)` should elide `b[o]..b[o+3]` | **Declined as spelled, and the chapter was wrong to promise it.** Fixed-width `o + 3` wraps (`20-types.md` §11.1), so the guard can hold for an `o` far past the end; the typechecker reports that shape as `OAK-T0701`. | **Documentation fixed** (`50-borrowing.md` "Offset bound"): the sound spelling is `len(b) >= u32(4) && o <= len(b) - u32(4)` (or `o < len(b) - 3` with `len(b) >= 3` known), which proves all four reads today (`guard_without_wrap`, `offset_under_bound`); the test pins both spellings. |
| R5 | Constant-fold `(a << k) \| b` in global initializers | **A codegen gap**: the shift routed through the checked helper, which is not a C constant expression. | **Landed** (`90-backend.md` §8a): in a constant context the shift is the plain operator at the checked width. |
| R6 | `mair_el1`, `sp_el0`, `elr_el1`, `spsr_el1` for the verified assembler | **Round one was wrong.** It pinned the four in the assembler's encoding table (`asm/sysregs_gen.go`, every register an `.oakasm` unit may name) and reported them present; the pilot's probe at 37808ed showed `arm64.write_mair_el1` and the other three missing, because the Oak-source library `arm64.read_X`/`write_X` is driven by a separate hand-written catalog (`semir/sysreg.go`) that did not carry them. | **Landed in round two**: the four are in the library catalog, read/write, with the MRS/MSR helpers, source signatures and effects the other registers have (`97-aarch64-system-registers.md` §1; `asm/sysreg_test.go`, `semir/sysreg_test.go`). The MMU register program and the EL0 entry can fold into the adapter. |
| R7 | FFI `Buffer[T]` + arena, and borrowing runtime memory in `unsafe` | **Already present**: `Buffer[T]` with custody states and Buffer fields in records (`92-ffi.md` §2.8), the `arena` package (`stdlib/arena.oak`). | **No change**; pointer to the chapter. |
| R8 | Resource contracts on function types, borrow-by-provenance (`OAK-B0111`) | **Already present**: `50-borrowing.md` §9 (contracts across callable boundaries, provenance, `OAK-B0111`–`B0115`). | **No change**; the capability and process tables can adopt `consume`/`borrowed` modes as written. |
| R9 | A time library (instants, civil time, RFC 3339) | **Already present**: `stdlib/time.oak` (`Instant`, `Duration`, `Civil`, `Zoned`, RFC 3339 text), with `timesim` and `timenative` realizations. | **No change.** |
| R10 | Inlinable emission or the maturing native backend | **Direction**, sequenced after R1 by the pilot itself. | Open. Hot pure functions already carry `OAK_INLINE`; a header-emitting mode is the increment when perf is on the critical path. |

## Round two (2026-09-13)

The pilot's second list, after the round-one migration: one new request
with the highest impact, one residual, one direction.

| # | Request | Determination | Disposition |
| --- | --- | --- | --- |
| R11 | `oak_index` must not materialize aggregate elements: `a[i][j]` over `[N][M]u64` copied a whole row per read, `a[i].f` a whole record | **A codegen gap, confirmed from the generated C.** The `oak_index` ternary yields an rvalue, so an aggregate element is copied out before the row index or the field is applied; the span/view path (R1) already selected in place. | **Landed** (`90-backend.md` §8): an aggregate element of an owned array is selected by address behind the checked index (`a.v[ oak_lv_idx(i, N) ]`), so `a[i][j]` and `a[i].f` are copy-free without hand-flattening; the check stays. |
| R3 residual | Page-table walk loops are not the canonical shape: the level index is `(va >> shift) & 511`, narrowed to `u32`, sometimes bound once and reused | **Confirmed** for the narrowing: the mask law applied to a bare `e & M` only, so `table[u32_trunc_u64((va >> 12) & 511)]` stayed checked, as did `idx = ...; table[idx]`. | **Landed** (`50-borrowing.md`, masked index): the mask survives a widening, an unsigned truncation and an unsigned saturation (`masked_trunc_under_length`, `masked_saturating_under_length`), and a binding initialized to a masked value is bounded by the mask until written. If a descend loop still shows checks (an index derived from a descriptor's output address, not a mask), send the loop. |
| R10 | Inline emission / native backend | **Direction**, unchanged. | Open; sequenced after the perf measurement of the walk. |
| R6, reopened | The four EL1 accessors, with the pilot's proof that the library lacked them | **Confirmed**; see the corrected R6 row above. | **Landed**: four catalog entries, and the x0 handoff the EL0 entry also wants: `arm64.eret_x0(arg) -> never` is ERET with its argument in `x0` at the instruction (`100-aarch64-control-transfer.md`, register handoff). The same entry is also legal today as an `.oakasm` unit (`system`, `bind`, `msr`, `mov x0, x3`, `isb`, `eret`); both forms are tested. The EL0 entry can fold into the adapter. |

## The native backend for the page-table ports (2026-09-13)

The pilot built the ports through the native backend (`oak build -native`)
and listed what blocks them; the C-backend differential stays the oracle.
The span idiom (`50-borrowing.md` §8e) is necessary and — for non-atomic,
shallow, non-large-stride ports — sufficient for native lowering: doorbell
and ring_pair lower with zero fallbacks; every residual fallback below is
a backend gap, not port style.

| # | Gap | Disposition |
| --- | --- | --- |
| N1 | Reads of top-level constants (`page_size`, `entries`) left the function to the C backend | **Fixed**: a read of a constant top-level scalar (integer or Bool) is folded to its value by the compiler — `codegen.ConstantScalarGlobals` names the set, the interpreter folds the initializers in declaration order as the C backend's own file-scope fold does — and handed to the native generator and the verifier as `asm.Function.Constants`, so it materializes as an immediate and the verifier reads it as that constant (`compiler/native_bodies.go`; `94-assembler.md` §9, sixteenth increment); the emitted C keeps the `static const`. `compiler/e2e_native_constants_test.go`. |
| N2 | Large record strides (`Regime` = 409 600 bytes) | **Fixed**: the element idiom builds a stride of 65 536 bytes or more as `movz` then `movk` before the `umaddl`, and a field past 4 095 bytes into the element is reached through `add … lsl #12` and a small remainder; the checker keeps the stride constant through the `movk` and narrows the region through the shifted add, the verifier steps both. `compiler/e2e_native_stride_test.go`: a 70 KiB record span's fields load and store natively and agree with the C backend. |
| N3 | Package-global scratch (`st`, `walk_null`, `trans_pa`) | **Fixed**: a mutable top-level scalar is addressed storage on the AArch64 lane — `adrp xA, G` then `add xA, xA, :lo12:G` name its cell and one `ldr`/`str` at the scalar's width reads or writes it; the checker admits exactly that shape (a page fact from the `adrp`, an address fact from the `add`, dying with the register and at calls; any other symbol, offset, index, or width is refused); the verifier proves a reader against its Oak body with the cell's entry value as a parameter of the proof and proves a writer cell by cell (the value each side leaves in every written cell must agree, through conditionals, for unit functions, and through calls — a callee's summary reads and writes the caller's cells); the C emitter gives the global external linkage under the label `oak_0g_<name>` the companion object references (a digit no function's mangled name can carry). `compiler/e2e_native_globals_test.go`: `st`/`walk_null`/`trans_pa`/`level`-shaped scratch written by one function, read by others across calls, `sum_state` proven; native exit == C exit. The rv64 lane addresses a global with `la` and the same cell rule. |
| N4 | Compound (multi-read) indexing of an owned-array field of a span element (`timer.next`, `virq.next_pending`); a single such access already lowered (ring_pair's `s[dom].sq[idx]`) | **Fixed**: the generator's type query resolved the array field by lowering the element address — every query emitted the guard and `add`/`umaddl` and pinned a scratch register that was never released, so the second read in a comparison or a nested `?` arm ran the pool dry and the refusal surfaced as "an index into … (not a span parameter)". Type queries now resolve arrays statically (`staticArrayOf`), the place error is reported as itself, and an array field of a view's element is readable (stores through it refused). `compiler/e2e_native_compound_test.go`: the pilot's `next_pending` shape, the same reads through a view, and a scan with the read in the loop condition all lower and agree with the C backend. |
| N6 | A deep expression exceeding the scratch-register budget fell back (`timer.take_expired`) | **Fixed**: when x9–x15 are all live the generator widens the pool — x16/x17 in a function without calls, then unclaimed callee-saved registers, saved in the prologue and restored in the epilogue and declared as clobbers — instead of leaving the function to C. `compiler/e2e_native_deep_test.go`: expression trees of depth 4 and 5 that fell back lower natively and agree with the C backend. True spilling to the frame remains the next step if a shape exhausts the widened pool. |
| N7 | An atomic operation on a span-element storage path (`atomic_load_acquire(s[dom].tail)`) fell back; the structure compiled, the atomic did not | **Fixed** (`65-machine-memory.md` §7a): the native subset had no atomics at all; now every builtin kind lowers when the cell is reached through a writable span — a `[*]Atomic[T]` element or an atomic field of a `[*]Record` element — as `ldar`/`stlr`, `dmb`, or the exclusive loop on the element address, checked at the seam and tested against the C backend. Bare literal indices (`c[0]`) are admitted as unsigned constants. Local cells and the rv64 lane remain with C. Unblocks the lock-free ports. |
| N5 | `oak build` had no object output — executables or `-emit-c` only — so a host-linked native differential test was not a flag flip | **Fixed**: `oak build -o name.o` on a hosted target compiles the emitted C to one relocatable object, asm units inlined (`115-tooling.md`, object output); a harness links it against its own driver. Until N2–N4 land, the freestanding on-path build under QEMU remains the validation route for stage2 and addr_space. |
| N8 | A store or load into an owned-array field of a span element whose index (or value) is a function call — `s[dom].pages[cell(i, j)]` in `stage2.reset` — was refused: `memory operands go through the declared sp frame or a bound span base; x12 is neither` (the inlined arithmetic lowered) | **Fixed**: the element address was computed first, spilled around the `bl`, and reloaded without the region fact the checker held before the call. Operands that call a program function are now evaluated before the place — value, then index, then the guarded element address — so the call's clobber precedes the facts. `compiler/e2e_native_call_index_test.go`: the pilot's `reset` shape with a calling index and a calling value in nested loops, and a read with a calling index; native exit == C exit. |
| N9 | Field and index modeling of package-global tables (`(table.slots).slot is not a record`, `not a span parameter`; caps, vcpu_sched, proc_table) | **Fixed**: a top-level record, or a written array, is an aggregate global — a record or array place at its `adrp`/`add` address, fields at their offsets and elements under the constant guard (an array of records inside through the scaled add from the field's base); the checker reads the address as a writable region of the aggregate's size and bounds every access inside it. `compiler/e2e_native_global_aggregates_test.go`: a global `Table` with an array-of-records field and a global `[16]u32` written and read across functions; native exit == C exit. Aggregate globals are trusted by the verifier; scalars keep their cell proofs. |

## What the round did not do

- It did not measure the stage2 walk. R2's effect is the C compiler's
  folding of a `static const`; the pilot's `stage2_bench.c` is the check.
- It did not change the wrapping contract of `+` (R4). The chapter now
  says what the checker does, and why.
