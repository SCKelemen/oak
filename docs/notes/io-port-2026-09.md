## Disposition summary

Of the checklist items with a bearing on the port: **yes** for the
principles (§1: trades written down, no hidden work, machine semantics),
bounds (§4: every access guarded with the `n <= len - base` shape, no
wrap), no allocation after init, deterministic simulation, provenance for
durability and detection, the FFI boundary as a validator, crash-vs-return,
stable codes; **no, now fixed** for §3 staging leaks between durable
scopes (F1), §4 secondary identity copies (F1), §9 canonical path shapes
(F6) and error precedence (F9), §11 reconciliation (F1–F17); **no, open**
for §5 function length and assertion density (F21), §7 `Thread.Block` was
no until F11; **partly** for §8 fault coverage (F19) and negative tests
(F18: every code now, `io_poll` and `Interrupted` not). Items with no
bearing — codecs, wire records, MMIO, parallel loops, typestate by design
(§7.3 chose slots) — are recorded as such in the agent's full table, kept
with the session.

## Verified claims

Checked against code and, where marked, by execution: the sector rule is
one predicate in both realizations and Lean, decided before any call,
admitting `n == 0`; the simulated region always serves the sector, the
native one probes once; `unlink` of a directory is `Invalid` here and
`Access` on Darwin (`EPERM`), and the consumer rightly asserts only `!=
0`; the two-part window split rules are identical in Oak and C for
`rename` and `readdir`; `readdir` writes NUL-terminated base names and
`TooLarge` on overflow with partial contents, the bound `n > out_len -
written` safe under the loop's invariant; `stat`'s window write and
`truncate`'s zero-fill; the link chain's order in both realizations; the
crash reverting to durable copies and `iosim_alloc` never reusing a
durably existing entry; `F_NOCACHE` accepting misaligned I/O so the
refusal of the misaligned tags is Oak's rule, as the spec says; the
fairness bound `bound + actors − 2 = 34`; the native realization rejected
under the simulation profile; one export surface across both realizations.
Lean ↔ spec: every §3 bullet but "Completion order" and the torn-write
prefix has a statement; `readBounded`, `rename_keeps_others`, and
`Entry.isDir` fixed for life have statements without a spec sentence.

## What the target taught the lists

Written back into `docs/checklists/correctness.md` and `performance.md`:
secondary identity copies of a freed entry (§4 Handles); measure a
function from its declaration to its closing brace (§5); one cursor for
configuration and operation draws (§8 Swarm); the simulation grants exactly
the contract, never more (§8, new); every refusal sentence needs a
differential tag (§8 Negative tests); path grammars as canonical encodings
and "compare the value, not a scalar derived from it" (§9); a
four-way-wrong request has a precedence (§9); partial results are the
port's outcomes (§10, new); the durability barrier is per host
(performance §8, new).
