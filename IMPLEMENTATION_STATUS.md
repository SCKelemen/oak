# Oak Implementation Status

This document is superseded. The **only authoritative status matrix** is
[`docs/spec/STATUS.md`](docs/spec/STATUS.md): a conservative
per-feature table of specification, implementation, tests, formal model,
proofs, and machine-checked refinement, updated with every milestone and
backed by the CI gates (Go test suite, golden corpus with C-compiler
checks, end-to-end native execution tests, and the Lean 4 proof build).

Historical claims previously in this file described aspirational or
partial states and are intentionally removed rather than left to drift.
